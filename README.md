# Mj-lnir-code

A minimal async Python client for the DeepSeek chat API.

## Setup

Create a virtual environment and install the dependency:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install openai
```

Set your DeepSeek API key as an environment variable:

```bash
export DEEPSEEK_API_KEY="your-api-key"
```

## Usage

```bash
python main.py
```

It sends a sample message to DeepSeek and prints the response.
